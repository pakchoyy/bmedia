ℹ️ Tentang BGY Prompt Game

Prompt Game v1.2 adalah AI-assisted instructional game generator dari ekosistem Bantu Guru Yuk. Membantu guru membuat prompt siap pakai untuk Gemini, Claude, atau Canva — dengan kualitas pedagogis yang lebih terukur.

✨ Cara Pakai

  1. Isi data pembelajaran (jenjang, kelas, mapel, materi, tujuan)
  2. Lihat rekomendasi tipe game dari BGY
  3. Sesuaikan desain game (tipe, tantangan, kesulitan, durasi, mode)
  4. Atur preferensi pembelajaran (asesmen, kondisi kelas, quality control)
  5. Klik Generate Master Prompt
  6. Salin prompt → buka Gemini / Claude / Canva → paste!
