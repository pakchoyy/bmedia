ℹ️ Tentang BGY Prompt Game

Buat Prompt Game Interaktif adalah bagian dari ekosistem Bantu Guru Yuk — platform gratis untuk guru Indonesia. Tool ini membantu kamu membuat prompt siap pakai untuk Gemini, Claude, atau Canva AI, sehingga kamu bisa punya game pembelajaran interaktif dalam hitungan menit.

✅ Sesuai Kurikulum Merdeka
Semua prompt dirancang sesuai prinsip Kurikulum Merdeka: diferensiasi pembelajaran, HOTS, asesmen autentik, dan pembelajaran yang menyenangkan.

✨ Cara Pakai

  1. Isi data pembelajaran (jenjang, kelas, mapel, materi)
  2. Lihat rekomendasi tipe game → klik "Gunakan Rekomendasi Ini"
  3. Sesuaikan di accordion (mode, kesulitan, durasi, gaya visual)
  4. Klik Generate Prompt Game
  5. Salin prompt → buka Gemini / Claude / Canva → paste! 🚀
